# Stravl — сайты и Telegram-боты

Портфолио Кирилла: сайты, Telegram-боты, услуги и связь с разработчиком.

## Запуск

Откройте папку проекта в VS Code. Запустите `index.html` через Live Server или откройте файл в браузере. Зависимости и сборка не требуются.

## Структура

- `index.html` — главная страница.
- `projects.html` — портфолио.
- `services.html` — услуги и начальные цены.
- `assets/styles.css` — оформление и адаптивные стили.
- `assets/app.js` — меню, фильтры, подробности проектов, демо бота и подготовка заявки.
- `assets/*.jpg` — скриншоты и изображение Stravl.

Файлы сайта находятся в корне репозитория и готовы для обычного статического хостинга, в том числе GitHub Pages. Включение GitHub Pages выполняется отдельно в Settings → Pages.

## Заявки

Контакт: [@Stravl001](https://t.me/Stravl001). Форма готовит черновик сообщения в браузере. Посетитель проверяет текст и отправляет его самостоятельно в Telegram. Серверной отправки и хранения заявок нет. Если клиент Telegram не подставляет текст из ссылки, есть кнопка копирования.

При изменении контакта обновите его во всех трёх HTML-страницах и `assets/app.js`. Цены и общие блоки также повторяются на трёх страницах.

## Проекты

Бот-магазин и квиз обозначены как учебные проекты. Для магазина сохранена исходная ссылка; работа бота зависит от запущенного сервера. Публичная ссылка на квиз пока не добавлена — доступны скриншоты и описание. Другие два бота можно добавить, когда будут материалы.

## Проверка

Проверены синтаксис JavaScript, локальные ресурсы, ссылки и якоря; десктопный и мобильный макет 390px; меню, фильтры, просмотр проекта, квиз, выбор услуги и подготовка сообщения.
